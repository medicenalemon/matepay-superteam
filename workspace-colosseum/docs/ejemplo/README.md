# Ejemplo completo (solo de referencia)

Un proyecto ficticio ("Caja del Club") con los cinco archivos que dejan las skills, para que vean cómo queda cada etapa:

| Archivo | Etapa |
|---|---|
| `01-idea.md` | `/solana-tuc-idea` |
| `02-validacion.md` | `/solana-tuc-validar` (con investigación real de Colosseum Copilot) |
| `03-mvp.md` | `/solana-tuc-mvp` |
| `04-plan.md` | `/solana-tuc-planificar` |
| `05-pitch.md` | `/solana-tuc-pitch` |

**No es el proyecto de tu equipo.** No lo copien a `proyecto/` ni construyan sobre esta idea sin pasar por `/solana-tuc-idea` y `/solana-tuc-validar`: ya hay varios proyectos parecidos en Colosseum (ver `02-validacion.md`).

Todo el ejemplo corre en **devnet**, la red de prueba de Solana (la plata es de mentira).
