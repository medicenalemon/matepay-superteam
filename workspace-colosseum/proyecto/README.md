# Carpeta `proyecto/`: la memoria del equipo

Acá guardan las skills el trabajo de cada etapa. Cada sesión nueva de Devin arranca sin memoria; estos archivos son lo que le devuelve el contexto.

| Archivo | Lo genera | Contiene |
|---|---|---|
| `01-idea.md` | `/solana-tuc-idea` | Equipo, problemas, ideas con puntaje, idea elegida |
| `02-validacion.md` | `/solana-tuc-validar` | Competencia, riesgos, test de mesa, veredicto |
| `03-mvp.md` | `/solana-tuc-mvp` | Alcance mínimo, guion de demo, definición de "listo" |
| `04-plan.md` | `/solana-tuc-planificar` | Bloques de trabajo y tareas para Devin |
| `05-pitch.md` | `/solana-tuc-pitch` | Deck, guiones de video, checklist de entrega |

Esta carpeta arranca **vacía a propósito**: cada archivo aparece cuando corren la skill correspondiente. Para ver cómo queda cada uno, hay un proyecto de ejemplo en `docs/ejemplo/` (no es el de ustedes).

Cuando aparezca un archivo nuevo, hagan commit. Si un dato cambia (nueva evidencia de validación, alcance recortado), vuelvan a correr la skill correspondiente para actualizarlo.
